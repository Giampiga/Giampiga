Contributed to a team's luxury-bag appraisal tool through client requirements, the v0 frontend journey, workflow testing, bug identification, and collaborative code review. **Complete appraisals measured roughly 2–3 minutes versus a 10–12-minute manual baseline** in prototype testing — about 75% less time. The prototype was not adopted by employees; the broader backend and AI services were team work.
